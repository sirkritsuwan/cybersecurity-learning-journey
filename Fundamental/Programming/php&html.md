- variable
`$' : can use with every data type

- display
  ```
  echo "abc <br>";

  // can use "" or ''
  //<br> : break / next line

  ex.
  $name = "Alice"
  $account = "123-456"
  $balance = 2336.33
  $active = true

  echo $name;
  echo "Account {$account} <br>";
  echo "Balance \${$balance}";       // use '\' to separate confusion of '$'
  echo "Active Status {$active}";    // true = 1, false = display nothing
  ```
